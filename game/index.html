アキバ・
ネオンクラフト

雨に濡れた夜のアキバ。路面にネオンが映る街を歩き、車や壁を壊して資材を集め、ブロックにして積み上げよう。

はじめから遊ぶと、毎回かんたんなチュートリアルから始まります(途中でやめられます)。

背景・小物はすべてコード生成(PBR質感・反射路面・ブルーム)。キャラクターは Tripo / Meshy の GLB に差し替えできます。

ポーズ

Esc で再開 / 進行状況はこのブラウザに自動保存されます

視点が速すぎるときは下げてください(タッチ操作にも反映されます)
0% で BGM を止めます(効果音はそのまま)
モデルの差し替え(Tripo / Meshy の GLB)
標準
読み込んだモデルはこのブラウザに保存され、次回も使われます。武器は「長い方向が前」になるよう向き・倒すで調整してください。
  • WASD 移動 / Shift ダッシュ / Space ジャンプ(一回押しで小ジャンプ・長押しで大ジャンプ) / V・マウスホイール押し 視点を元に戻す
  • 画面の輪の上の赤い矢印は、画面の外にいる敵の方向(上=前・下=後ろ)。ピンクの大きい矢印はボス。出現したばかりの敵は点滅します
  • E・左クリック 攻撃(押しっぱなしで連続) / B 戦闘↔建築モード / F・右クリック 設置(建築モード)
  • C クラフト: ダイナマイト・ネオンソード・エネルギーガンを作れます(1〜4で持ち替え、Rでリロード、銃は右クリック長押しでのぞき込み、ネオンソードは右クリックで薙ぎ払い)
  • 1〜6 資材選択 / R 形の切替(ブロック→階段→床板)
  • ロボを倒すほど敵が少しずつ強くなります。画面上のメーターが満タンになると、10体で中ボス、続けて20体で大ボスが出現します
  • ミニマップ: 金の点=ゴールドカプセル(屋上) / 緑=宝箱 / 赤=ガチャロボ。ロボは倒すと資材やポーションを落とします
  • 画面中央が指す面の隣に置けます。真下を見ると足元の隣に置け、ジャンプ中に真下を見て置くと足場を積み上げられます
  • 建築は「地面」「設置済みの建築の隣」「階段の先」「建物の壁の近く」にだけ置けます(枠が黄=置ける / 赤=置けない)
  • 脇道の突き当たりの宝箱をE・左クリックで開けると緑のポーション入手 / Qで使用(HP+50)
  • 階段で屋上へ。3m超の落下でダメージ、ビル最上部からの落下でHP100が0になります
